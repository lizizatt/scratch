# Monster Token progression proposal

## Decision

Use the class-specific Monster Hunter armor as the party's next armor
progression, but buy for **high-value effects and two-/three-piece breakpoints**
rather than completing one set at a time.

The first planned spend is:

| Character | Pieces | Cost | Immediate reason |
|---|---|---:|---|
| Sarene | Mage hat, gloves, pants | 26 | Three-piece bonus: +5 INT and +2 speed; the hat also has 40 resistance piercing |
| Zarook | Priest gloves, hat, pants | 26 | Three-piece bonus: +6 INT and +2 speed; the gloves also add 5 damage output |
| Jazwyn | Warrior gloves | 8 | Clear glove upgrade with 1 crit |
| **Total** | 7 pieces | **60** | Leaves 4 of the currently estimated 64 tokens |

This approves the Hunter-set direction without claiming that four complete
sets are the best immediate use of 212 tokens. Full sets remain later targets,
especially for Jazwyn. Puppygirl's set is useful but follows the combat trio.

This is a **current-progression BIS plan** for the party's present levels,
inventory, and operating model. It is not a claim about theoretical endgame
BIS.

## Evidence and budget

The item and token facts in this document were checked against official
Adventure Land game data version **15650**.

The working balance is **64 Monster Tokens**:

- 41 observed on Puppygirl;
- 23 in the most recent bank snapshot.

The bank service marked its snapshot age as unverified. Refresh and recount the
bank immediately before spending. The plan remains useful if only the 41 bag
tokens are available:

1. Buy Sarene's three-piece core for 26.
2. Buy Zarook's gloves and hat for 15.
3. After the bank stack is confirmed, buy Zarook's pants for 11 and Jazwyn's
   gloves for 8, leaving 4.

Normal-server Monster Hunt completion awards one Monster Token. Merchants
cannot accept Monster Hunts, so Puppygirl's set must be funded by the fighters'
quest throughput.

There are five-piece Hunter sets for Warrior, Mage, Priest, Ranger, Rogue, and
Merchant. Every set costs 53 tokens: 7 + 8 + 11 + 12 + 15. Ranger and Rogue
pieces have no current user in this party and should not be purchased.

All Hunter pieces are class-locked, have no character-level requirement, and
are upgradeable. Their first grade boundary is zero, so they require the
higher-grade upgrade path from the first attempt rather than the cheap
`scroll0` path used for ordinary armor.

## Purchase and upgrade gates

Do not automate the purchases yet. The current code safely coordinates
accessories, but Hunter armor exposes four gaps:

1. Party-wide coordination does not yet allocate armor slots.
2. `score()` does not model set bonuses, crit, piercing, output, speed, or the
   equipped item's `stat_type`, so it cannot prove these loadout decisions.
3. Automatic upgrades are restricted to a `scroll0` allowlist and grade-zero
   items. Hunter equipment is neither allowlisted nor grade zero at +0.
4. A bought piece needs an explicit, auditable route from Puppygirl to the
   correct class before it can be treated as delivered.

Before spending, add Hunter pieces to a reviewed purchase manifest and make the
delivery/equip flow understand class, complete-loadout score, set breakpoints,
and replacement retention. Upgrade each initial piece only through a
high-grade policy with an explicit gold/scroll budget. Retain displaced gear
until live tooltips and combat logs prove the replacement.

## Adversarial review record

1. **Proposal:** buy all four complete class sets.
   **Objection:** 212 tokens exceeds the estimated 64-token balance; high-grade
   upgrades are expensive; several upgraded current pieces beat Hunter +0.
   **Revision:** optimize breakpoints instead of completing sets.
2. **Proposal:** buy three pieces for every fighter.
   **Objection:** the useful combinations cost more than the current balance
   and ignore unique standalone effects.
   **Revision:** complete Mage and Priest three-piece cores and buy Warrior
   gloves.
3. **Proposal:** spend 60 on those seven pieces.
   **Objection:** this delays Merchant gold gloves and Tracktrix.
   **Resolution:** combat throughput and healer stability generate future
   tokens; Puppygirl is not gold-constrained, while Tracktrix has no combat
   stats.
4. **Catalog review:** the first independent catalog omitted the 12-token
   Paladin-only Concord Mace.
   **Correction:** it is included above and rejected because this party has no
   Paladin.
5. **Codebase review:** item merits alone do not make the plan operationally
   safe.
   **Correction:** purchases are gated on armor-aware coordination, set-aware
   scoring, high-grade upgrade policy, and delivery verification.
6. **Final rules review:** Priest gloves' `output: 5` was initially treated as
   healing throughput.
   **Correction:** server calculation applies output to attack after healing is
   snapshotted, so the property improves damage only. The Priest three-piece
   recommendation rests on INT, speed, and defenses.
7. **Final source review:** the pinned repository token table predates Concord
   Mace.
   **Correction:** live version-15650 `G.tokens.monstertoken` is authoritative
   for that 12-token Paladin-only reward.
